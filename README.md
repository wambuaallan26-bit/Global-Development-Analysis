# 🌍 Global Development Analysis Using Machine Learning

## Project Overview
This project uses Exploratory Data Analysis (EDA) and unsupervised machine learning techniques to analyze and group countries based on economic, health, and social indicators.

## Techniques Used
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Scaling
- K-Means Clustering
- Hierarchical Clustering
- Elbow Method and Silhouette Score
